# 按键绑定
## 按键绑定
在godot里，通过点击“项目”，在项目里的“项目设置”中的“输入映射”里可以快速绑定按键事件（键盘和手柄都有）
## 按键事件触发
```python
var direction: Vector2 = Vector2.ZERO
var speed: int = 5

func _physics_process(_delta: float) -> void:
	direction = Input.get_vector("left","right","up","down")
	position += direction * speed
	
	if Input.is_action_just_pressed("confirm"):
		print("start")
```
函数 ~={green}Input.get_vector=~是一个对方向按键的包装函数，直接写入方向按键绑定，实现按按键触发，不按按键不触发
函数 ~={green}Input.is_action_pressed=~在~={red}func _physics_process=~（默认60帧）里会每个16s检测一次按键状态，导致频繁触发
函数 ~={green}Input.is_action_just_pressed=~是通过检测按键是否按下来触发事件，可以防止频繁触发
==这两个函数的返回值都是~={red}布尔值=~==
