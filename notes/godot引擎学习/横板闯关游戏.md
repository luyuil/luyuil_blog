## 向量归一化处理
godot内置可以获取鼠标点击坐标，这是一组向量数据，有方向有大小，我们用向量方向乘子弹速度就是子弹的基本逻辑，而大小会影响这个结果，所以向量的归一化就是使获取到的向量大小为1，只使用向量的方向，godot内置了这些函数
```python
# 前面是获取鼠标点击坐标，后面是归一化
get_local_mouse_position().normalized()
```
## 子弹生成和移动
生成以自身坐标，且要根据鼠标点击的事件触发
但是这套逻辑要在level.gd里运行，但是上面的在player.gd中才可以获取
解决方法是在player.gd创建一个自定义信号——shoot
这个信号连接level.gd脚本
自定义信号用signal
player.gd 代码如下：
```python
signal shoot(pos: Vector2, dir: Vector2)

func get_input():
	direction_x = Input.get_axis("left","right")
	
	if Input.is_action_just_pressed("jump"):
		velocity.y = -jump_strength
	if Input.is_action_just_pressed("shoot") and $ReloadTimer.time_left == 0:
		var dir = get_local_mouse_position().normalized()
		# 发射信号，传递position和dir两个参数
		shoot.emit(position, dir)
		print("shoot")
		$ReloadTimer.start()
```
level.gd代码如下：
```python
func _on_player_shoot(pos: Vector2, dir: Vector2) -> void:
	
	#创建子弹场景实例
	var bullet = bullet_scene.instantiate() as Area2D
```

## 上半身
```python
func update_torso_aim():
	var dir = get_global_mouse_position() - global_position
	var angle = dir.angle()  # 返回值范围：-PI ~ PI，0 表示正右方
	
	# 把负数角度转成 0~2PI，方便计算
	if angle < 0:
		angle += 2 * PI
	
	# 8个方向，每个占 45度(PI/4)
	# round() 四舍五入得到最近的方位，%8 防止溢出到第8帧
	var frame = int(round(angle / (PI / 4))) % 8
	$Torso.frame = frame
```
