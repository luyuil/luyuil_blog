# 帧
游戏本质就是依次播放帧，电影通常是每秒24帧，电子游戏则需要达到每秒30帧，而游戏引擎就是根据逻辑判断渲染帧，每秒起码渲染30次
# 场景和节点
#制作游戏的核心基础
## 节点
最基础的组成单元，可以是图片，音效，计时器，动画播放器等等
在一个场景中组合各类节点
节点有~={purple}父节点=~和~={blue}子节点=~，父节点会影响所有的子节点，子节点不会影响父节点，只会改变本身
## 场景
- 场景充当节点的容器
- 管理显示的内容
# 窗口坐标系
规定（以 1152 x 648 为例）：窗口的左上角为原点$(0,0)$，原点往右，x轴增加，最多到1152；原点往下，y轴增加，最多到648。
