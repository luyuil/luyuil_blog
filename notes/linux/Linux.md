# 命令和命令行
- 命令行：即Linux终端，是一种命令提示符页面。以纯“字符”的形式操作系统，可以使用各种字符化命令对系统发出操作指令。
- 命令：即Linux程序。一个命令就是一个Linux的程序。命令没有图形化页面，可以在命令行提供字符化的反馈。
无论是什么命令，用于什么用途，在Linux中，命令有其通用的格式：
```bash
command [-options] [parameter]
```
- command：命令本身
- -options：[可选，非必填]命令的一些选项，可以通过选项控制命令的行为细节
- parameter：[可选，非必填]命令的参数，多数用于命令的指向目标等
举个例子
```bash
ls -l /home/work
```
意思是以列表的形式，显示/home/work目录内的内容
# ls 命令
ls命令的作用是列出目录下的内容，语法细节如下：
```bash
ls [-a -l -h] [Linux路径]
```
- -a -l -h 是可选的选项
- Linux路径是此命令可选的参数
当不使用选项和参数，直接使用ls命令本体，表示：以平铺形式，列出当前工作目录下的内容
![[Linux-1788421311380.webp]]
## 什么是当前目录
- 当前登录用户的HOME目录作为当前工作目录，所以ls命令列出的是HOME目录的内容
- HOME目录：每个Linux操作用户在Linux系统的个人账户目录，路径在：/home/用户名
## ls命令的选项
- -a：表示all的意思，即列出全部文件（包含隐藏的文件/文件夹）
- -l：表示已列表（竖向排列）的形式展示内容，并展示更多信息
- -h：表示以易于阅读的形式，列出文件大小，如K，M，G。（-h选项必须要搭配-l一起使用）
命令选项是可以组合使用的
```bash
ls -l -a
ls -la
ls -al
ls -lh
```
# cd/pwd命令
## cd命令
当Linux终端打开的时候，会默认以用户的HOME目录为当前的工作目录
我们可以通过cd命令，更改当前所在的工作目录。
语法如下：
```bash
cd [Linux路径]
```
- cd命令无需选项，只有参数，表示要切换到哪个目录下
- cd命令直接执行，不写参数，表示回到用户的HOME目录
## pwd命令
来查看当前所在的工作目录。
- pwd命令，无选项，无参数，直接输入pwd即可
```bash
pwd
```
# 相对路径，绝对路径和特殊路径符
## 相对路径和绝对路径
- 绝对路径：以跟目录为起点，描述路径的一种写法，路径描述以/开头
![[Linux-1788435022329.webp]]
- 相对路径：以当前目录为起点，描述路径的一种写法，路径描述无需以/开头
![[Linux-1788435076904.webp]]
当前在home目录下，直接cd Desktop可以直接进入到Desktop目录
## 特殊路径符
- .   表示当前目录，比如cd ./Desktop 表示切换到当前目录下的Desktop目录内，和cd Desktop效果一致
- ..  表示上一级目录，比如cd .. 即可切换到上一级目录，cd ../.. 切换到上二级的目录
- ~ 表示HOME目录，比如cd ~即可切换到HOME目录或cd ~/Desktop，切换到HOME内的Desktop目录
# mkdir命令
通过mkdir命令可以创建新的目录（文件夹）
语法如下
```bash
mkdir [-p] Linux路径 
```
- 参数必填，表示Linux路径，即要创建的文件夹的路径，相对路径或绝对路径均可
- -p选项可选，表示自动创建不存在的父目录，适用于创建连续多层级的目录
![[Linux-1788436882149.webp]]

> [!NOTE] 注意
> 创建文件夹需要修改权限，请确保操作均在HOME目录内，不要在HOME外操作
> 涉及到权限问题，HOME外无法成功
