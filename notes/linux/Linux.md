# 命令和命令行
- 命令行：即Linux终端，是一种命令提示符页面。以纯“字符”的形式操作系统，可以使用各种字符化命令对系统发出操作指令。
- 命令：即Linux程序。一个命令就是一个Linux的程序。命令没有图形化页面，可以在命令行提供字符化的反馈。
无论是什么命令，用于什么用途，在Linux中，命令有其通用的格式：
```bash
command [-options] [parameter]
```
- command：命令本身
- -options：[可选，非必填]命令的一些选项，可以通过选项控制命令的行为细节
- parameter：[可选，非必填]命令的参数，多数用于命令的指向目标等
举个例子
```bash
ls -l /home/work
```
意思是以列表的形式，显示/home/work目录内的内容
# ls 命令
ls命令的作用是列出目录下的内容，语法细节如下：
```bash
ls [-a -l -h] [Linux路径]
```
- -a -l -h 是可选的选项
- Linux路径是此命令可选的参数
当不使用选项和参数，直接使用ls命令本体，表示：以平铺形式，列出当前工作目录下的内容
![[Linux-1788421311380.webp]]
## 什么是当前目录
- 当前登录用户的HOME目录作为当前工作目录，所以ls命令列出的是HOME目录的内容
- HOME目录：每个Linux操作用户在Linux系统的个人账户目录，路径在：/home/用户名
## ls命令的选项
- -a：表示all的意思，即列出全部文件（包含隐藏的文件/文件夹）
- -l：表示已列表（竖向排列）的形式展示内容，并展示更多信息
- -h：表示以易于阅读的形式，列出文件大小，如K，M，G。（-h选项必须要搭配-l一起使用）
命令选项是可以组合使用的
```bash
ls -l -a
ls -la
ls -al
ls -lh
```
# cd/pwd命令
## cd命令
当Linux终端打开的时候，会默认以用户的HOME目录为当前的工作目录
我们可以通过cd命令，更改当前所在的工作目录。
语法如下：
```bash
cd [Linux路径]
```
- cd命令无需选项，只有参数，表示要切换到哪个目录下
- cd命令直接执行，不写参数，表示回到用户的HOME目录
## pwd命令
来查看当前所在的工作目录。
- pwd命令，无选项，无参数，直接输入pwd即可
```bash
pwd
```
# 相对路径，绝对路径和特殊路径符
## 相对路径和绝对路径
- 绝对路径：以跟目录为起点，描述路径的一种写法，路径描述以/开头
![[Linux-1788435022329.webp]]
- 相对路径：以当前目录为起点，描述路径的一种写法，路径描述无需以/开头
![[Linux-1788435076904.webp]]
当前在home目录下，直接cd Desktop可以直接进入到Desktop目录
## 特殊路径符
- .   表示当前目录，比如cd ./Desktop 表示切换到当前目录下的Desktop目录内，和cd Desktop效果一致
- ..  表示上一级目录，比如cd .. 即可切换到上一级目录，cd ../.. 切换到上二级的目录
- ~ 表示HOME目录，比如cd ~即可切换到HOME目录或cd ~/Desktop，切换到HOME内的Desktop目录
# mkdir命令
通过mkdir命令可以创建新的目录（文件夹）
语法如下
```bash
mkdir [-p] Linux路径 
```
- 参数必填，表示Linux路径，即要创建的文件夹的路径，相对路径或绝对路径均可
- -p选项可选，表示自动创建不存在的父目录，适用于创建连续多层级的目录
![[Linux-1788436882149.webp]]

> [!NOTE] 注意
> 创建文件夹需要修改权限，请确保操作均在HOME目录内，不要在HOME外操作
> 涉及到权限问题，HOME外无法成功

# cp命令
cp命令可以用于复制文件\文件夹
```
cp [-r] 参数1 参数2
```
- -r选项，可选，用于复制文件夹使用，表示递归
- 参数1，Linux路径，表示被复制的文件或文件夹
- 参数2，Linux路径，表示要复制去的地方
# mv命令
mv命令可以用于移动文件和文件夹
```bash

```
参数1，Linux路径，表示被移动的文件或文件夹
参数2，Linux路径，表示要移动去的地方，如果目标不存在，则进行改名，确保目标存在
# rm命令
rm命令可用于删除文件，文件夹
```bash
rm [-r -f] 参数1 参数2 ... 参数n
```
- -r选项用于删除文件夹
- -f表示force，强制删除
- 参数表示要删除的文件和文件夹路径，按照空格隔开

# find命令
通过find命令去搜索指定的文件
```bash
find 起始路径 -name "被查找的文件名"
```
find命令也可以搭配通配符使用
最好搭配root用户使用，可以搜索所有文件
## 按文件大小查找文件
```bash
find 起始路径 -size +|- n[kMG]
```
- + - 表示大于和小于
- n 表示大小数字
- kMG 表示大小单位，k表示kb ，M表示MB，G表示GB
实例
```bash
find / -size -10k
find / -size +100M
find / -size +1G
```
# grep命令
可以通过grep命令，从文件中通过关键字过滤文件行
```bash
grep [-n] 关键字 文件路径
```
- 选项-n，可选，表示在结果中显示匹配的行的行号
- 参数，关键字，必填，表示要过滤的关键字，带有空格或其他特殊符号，建议使用""将关键字包围起来
- 参数，文件路径，必填，表示要过滤内容的文件路径，可作为内容~={red}输入=~端口
![[Linux-1788575403470.webp]]
# wc命令
可以通过wc命令统计文件的行数，单词数量等
```bash
wc [-c -m -l -w]文件路径
```
- 选项， -c 统计bytes数量
- 选项，-m 统计字符数量
- 选项，-l 统计行数
- 选项，-w 统计单词数量
- 参数，文件路径，被统计的文件，可作为内容~={red}输入=~端口

# echo命令
可以使用echo命令在命令行内输出指定内容
```bash
echo 输出内容
```
- 无需选项，只有一个参数，表示要输出的内容，复制内容可以用""包围
- 带有空格或\等特殊符号，建议使用双引号包围（因为如果不包围的化，空格后很容易被识别为参数2，尽管echo不受影响，但要养成好习惯）
# 反引号\`\`
![[Linux-1788577343957.webp]]

# 重定向符

- >> 将左侧命令的结果，追加写入到符号右侧指定的文件中
# tail命令
使用tail命令，可以查看文件尾部内容，跟踪文件的最新更改
```bash
tail [-f -num] Linux路径
```
- 参数，Linux路径，表示被追踪的文件路径
- 选项，-f，表示持续追踪
- 选项，-num，表示查看尾部多少行，不填默认10行
